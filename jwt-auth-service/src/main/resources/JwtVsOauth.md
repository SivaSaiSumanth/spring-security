## JWT vs OAuth 2.0

| JWT                                              | OAuth 2.0                                                              |
| ------------------------------------------------ | ---------------------------------------------------------------------- |
| A token format                                   | An authorization framework                                             |
| Defines how claims can be represented and signed | Defines how clients obtain and use authorization                       |
| Can be validated by a resource server            | Defines the authorization flows and roles involved                     |
| Example: Your `JwtService` creates a JWT         | Example: A client obtains an access token from an authorization server |
